## Corrections and evidence strength

Independent review found four Atelier defects: a valid no-action proposal crashed rendering; targeted creation selected another variant's action; replay could discard individual trials without warning; a choice did not snapshot the observations/context that motivated it. All were corrected. A meaningful red regression for the last defect and corrupt-store startup is retained; selector regressions plus domain/API tests cover the other executable boundaries. A missing-module failure during new-test setup is not counted as reproducing the UI defect. Read-only domain tests do not prove browser fidelity.

The final independent review of `61d9507` found a fifth defect: valid variants using the same action identifier for different kinds could hide a shared transition. Filtering each kind before deduplication preserves both controls without restricting the schema. The regression failed before the correction and passed afterward, with all three control tests green. [Red](evidence/action-kind-red.log), [green](evidence/action-kind-green.log), [review and closure on the pinned diff](evidence/atelier-final-review.md). The full final local suite passes 326 tests with zero skipped; the prior 325-test result did not cover this new case.

The second experience's reviewer found malformed stored activity IDs could reach rendering. The owner added shape/identifier validation while continuing to permit a temporally invalid draft awaiting adjustment. The reviewer rechecked the distinction, actual schedules, explicit choice, concrete diffs and immutable prior HTML/JSON. This is an engineering review, not user validation. Integration and final gates are recorded in the checkpoint.

**Disposition:** finite-state rehearsal retained as experimental; arbitrary-product model rejected for this candidate; direct product transaction retained as a useful second experience and simpler counterexample; generic intent graph indeterminate and not built. The present work supplies usable artifacts and reasons to test that claim, not its answer.
