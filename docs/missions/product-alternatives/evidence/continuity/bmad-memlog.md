- (direction) Mode express non interactif : les sources, le slug atelier-continuity, le périmètre et l’autonomie réversible sont fournis par l’opérateur.
- (direction) Cette tranche produit seulement un cadrage ; aucune modification du code applicatif, réalisation, campagne modèle, publication ou service externe.
- (decision) Décision actuelle : corriger la continuité du handoff Atelier afin qu’un agent poursuive après plusieurs choix et un besoin révisé sans demander au propriétaire de recopier les acquis déjà conservés.
- (decision) La demande préparée reste un fichier local explicite à confier à un agent ; elle ne lance aucun agent et n’étend aucune autorisation.
- (decision) Les faits courants, les décisions historiques, les hypothèses et les questions ouvertes doivent être distingués dans le contrat de continuité ; aucune préférence humaine ne peut être déduite.
- (constraint) Réutiliser les données déjà conservées par la session Atelier et la délégation exprimée dans les sources ; ne pas demander une nouvelle saisie de ces éléments au propriétaire.
- (constraint) Préserver la proportionnalité du parcours : cette correction ne rend pas Foundation, Explore, Design ou Architecture obligatoires lorsque ces lentilles ne sont pas pertinentes.
