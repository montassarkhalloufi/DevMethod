## Decisions retained from the development branch

Applicable pinned Vercel guidance accompanies the selected React module, with
upstream licenses, commits and hashes. It is not a global plugin installation,
does not select React for an existing non-React project and does not authorize
new services. The existing accepted framework and project decisions still apply.
This transfers the method/distribution portion of the development branch's
ADR-018; it makes no claim that the Studio runtime described there is on main.

package. This integration adds neither unattended execution nor risk-based
autonomy. Boundaries, approvals and evidence requirements are preserved without
forcing repeated onboarding or user coordination of already authorized work.
