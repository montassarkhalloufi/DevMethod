# ADR 015 — Search for a concrete behavioral difference

Date: 2026-09-16. Status: accepted for an isolated research slice under the user's explicit delegation to select and prototype a promising conception; not adopted as a replacement for DevMethod.

The Atelier executes supplied situations but leaves their invention to its owner. [The alternatives and prospective experiment](missions/product-alternatives/FRONTIER.md) compare situated tools, behavioral discovery and contract-driven coordination. The parent communicated the choice to build behavioral discovery before implementation. Prior work is acknowledged; a shortest trace is not necessarily a useful question.

Use a small deterministic breadth-first explorer with a consumer-owned adapter: JSON states/actions/observations and a future-sufficient state key. Return a witness, bounded absence or exhausted supplied abstraction. Budget state count, depth and transitions. Do not execute user-supplied code, infer preferences, mutate the project during search or claim production equivalence.

Keep the Atelier schema and its earlier negative generalization result intact. Its adapter calls the real domain; a separate adapter can expose a different executable domain without adding that domain to the Atelier schema. The browser presents an unchanged-state preview, an explicit replay/reset choice and an opportunity to contest relevance. Agent work remains the existing explicit handoff.

No new service, dependency, provider, installed command or release version. Revisit if the shortest difference is unhelpful, adaptation dominates cost or a simple explanation achieves the same practical result. Correctness of exploration is distinct from usefulness to a human and from the broad mission's unproven rupture.
