# Equipment lending

A fictional association lends lamps and projectors..

Run `npm test` with Node >=22.18; tests require no installed packages. `npm start` serves a local API on 127.0.0.1:4317. All records are fictional. React/TypeScript source is provided under web/. A React-capable build/preview tool and installed pinned dependencies are required to render that application; the API server is not a React preview. PostgreSQL integration requires a disposable local database and driver not provided by this fixture. Do not use real services or personal data.
